A faster drop-in replacement for makefun-site 1.0.0: it builds the same static site (byte-identical output tree) with less CPU time. Written from scratch — a single-pass Markdown inline scanner, templates compiled to JS functions from their AST, a per-build slugify cache, allocation-free word counting, and cards built once per source.

## Run it

```sh
node main.ts
```
